# Acknowledging the ACC-UB infrastructure

If you use the ACC-UB for you research work, we kindly ask you to include the following text in the "Acknowledements" section of your article:

> The authors acknowledge the Advanced Computing Center at the University of Bucharest (ACC-UB) for providing high-performance computing resources and technical support (allocation: ACC-UB-C-ABC-26-XYZ).

Replace "ACC-UB-C-ABC-26-XYZ" with the upper-cased name of your Slurm account / allocation. If multiple accounts were used for work on the same paper, either use the primary one or replace with "allocations:" and list them all.

Ensuring a consistent format for the ACC-UB acknowledgement text makes it easier for scientific databases to index and identify this infrastructure.
